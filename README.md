# The Big Year - bird call pages

Each CALL card's QR code opens `https://chantelombaard99.github.io/bigyearboardgame/#<CARD-ID>` (e.g. `#KRU-01`).
The page plays `calls/<file>` listed for that card in `calls.json` - without showing the bird's name.

- `calls.json`: card ID -> file, bird, recordist, licence, source.
- `calls/`: the audio files (from xeno-canto.org, Creative Commons, credited on `credits.html`).
